OPTIONS

GAME RULE

勝利条件を変更します。基本ルールはSTANDARDです。
勝利条件 4種類完成時の追加条件

PLACEMENT RULE

縦・横・2×2エリアで、同じ形をどこまで禁止するか変更します。
同形駒の配置制限 CPUも同じ配置条件で思考します
ALL：自分・相手を問わず同形禁止
OPPONENT ONLY：相手の同形だけ禁止

START ORDER

対局開始時の先攻・後攻を設定します。RANDOMはリセット時にも再抽選します。
開始順 CPU戦ではPLAYER 1＝あなた、PLAYER 2＝CPU

PIECE SELECT

配置する形を自分で選ぶか、相手が選ぶかを変更します。
駒の選択方式 CHOICEでは相手が次に配置する形を指定
SELF：配置するプレイヤーが自分で形を選択
CHOICE：相手が形を指定し、指定されたプレイヤーが置き場所を決定
※合法な置き場所がない形はCHOICE候補から除外されます

TURN TIMER

各手番の制限時間です。時間切れになったプレイヤーはその場で敗北します。
時間制限 2 PLAYERS / VS CPU 共通
1手の制限時間 手番が移るたびにリセット

ASSIST

ルールそのものではなく、盤面を読みやすくする補助機能です。
配置可能マス表示 選択後、合法マスを緑枠表示
配置不可マス暗転 配置できないマスを薄く表示
配置不可理由表示 不可マスを押したとき理由を表示

DISPLAY

1台のiPhoneを向かい合って使うための表示設定です。
PLAYER 2を180°回転 向かい側から読みやすく表示
設定はこの端末内に自動保存されます。
